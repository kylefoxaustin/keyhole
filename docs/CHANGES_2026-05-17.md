## The conceptual frame that drove this

Kyle issued a brief on 2026-05-17 redefining product scope:

> *"Keyhole is an edge AI video analytics platform. The product
> deliverable is a vision pipeline that runs on NPU-class silicon.
> The LLM is an optional feature of the Keyhole product, not a
> parallel deliverable. It is the same artifact that ships as the
> Skippy / personal-AI product."*

Three operational modes the deck must acknowledge:

1. **Vision-only** — vision pipeline runs; LLM off. Default video-
   analytics deployment.
2. **Vision + LLM** — both run; LLM acts on vision data (NLQ over
   the event store, agentic scene queries). Engineering question =
   NPU coexistence.
3. **LLM-only** — vision pipeline off; LLM standalone. Equivalent to
   the Skippy product running inside keyhole-sizer.

Rule: training-methodology content (recipe taxonomy, headline-erosion
arc, cross-family base bake-offs) belongs in the Skippy product deck
only. Keyhole references rather than reproduces.

The brief also originally claimed NPU Mid was FP-capable on a
different memory bus from High. **That claim was corrected same-day:**
PAI deck slide 11 is the golden source. Mid is INT8-only; Mid + High
share 8.4 GT/s.
